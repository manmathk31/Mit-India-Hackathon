# Model Weights Directory

Place your custom trained YOLO ONNX model here:
- Filename: `damage_yolo.onnx`
- Default Path: `image_agent/models/damage_yolo.onnx`

> [!NOTE]
> If `damage_yolo.onnx` is not present, the `image_agent` microservice automatically falls back to **Gemini 3.5 Flash-Lite** vision with zero crashes.
